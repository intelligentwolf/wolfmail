# Contributing

Thank you for your interest in WolfMail.

WolfMail is open source under the GNU GPL v3.0 or later, so you are free to use, study, change and share it under that
licence. However, **IntelligentWolf Ltd does not accept external code contributions**: pull requests from outside the
team are closed automatically, and all changes are written and reviewed in-house.

- **Found a bug or have an idea?** Please open an [issue](../../issues).
- **Security problem?** Please report it privately — see [SECURITY.md](SECURITY.md).
